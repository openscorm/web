DOMPurify (dompurify 3.4.14)
----------------------------

DOMPurify is dual-licensed "MPL-2.0 OR Apache-2.0" and enters the dependency
tree through posthog-js. Where a component offers a choice, the recipient
elects. OpenSCORM elects the Apache License, Version 2.0, and does not rely
on the Mozilla Public License 2.0 grant.

The Apache License, Version 2.0 is available at:
http://www.apache.org/licenses/LICENSE-2.0

DOMPurify is not currently emitted into the build. The bundler removes it
because the posthog-js code path that uses it is never reached, so no copy
of it is distributed today and no Apache-2.0 notice obligation is live. The
election above is recorded in advance so that it holds without further
decision if a later build does include it.
